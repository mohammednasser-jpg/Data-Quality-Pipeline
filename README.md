وع العمل: هندسة بيانات وتدقيق الجودة (Data Quality Pipeline).

في هذا المشروع، قمت بتصميم مسار بيانات لمعالجة الآلاف من الحركات المالية (Transactions) واكتشاف الشذوذ فيها.

طريقة التنفيذ والميزات:

بناء سكريبت بايثون لاستخراج البيانات المالية الخام.

تطبيق فلاتر جودة البيانات (Data Quality Checks) لاكتشاف السجلات الخاطئة، مثل المبالغ السالبة غير المنطقية أو أرقام الحسابات المفقودة.

فصل البيانات الفاسدة في ملف خاص (للمراجعة)، وتصدير البيانات السليمة والموثوقة فقط إلى ملف نهائي جاهز للتحليل المالي أو لوحات المعلومات.

أتمتة العملية بالكامل باستخدام مكتبة Pandas لتوفير الوقت وتقليل الأخطاء البشرية.
